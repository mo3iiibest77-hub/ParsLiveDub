کلید Gemini API

کلید رایگان را از Google AI Studio بگیرید و اینجا ذخیره کنید. کلید فقط روی دستگاه شما می‌ماند.

نحوه استفاده

  1. کلید API را ذخیره کنید.
  2. به یوتیوب یا هر صفحه دارای صدا بروید.
  3. روی آیکون افزونه کلیک کنید و «شروع دوبله» را بزنید.
  4. صدا به صورت زنده به فارسی ترجمه و پخش می‌شود.

نکات

  • بهترین عملکرد با هدفون.
  • روی Chrome دسکتاپ و Lemur Browser اندروید تست شده.
  • هزینه بر اساس کلید خودتان محاسبه می‌شود (سطح رایگان معمولاً کافی است).
