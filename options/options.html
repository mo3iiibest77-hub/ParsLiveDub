کلید Gemini API

کلید رایگان خود را از Google AI Studio بگیرید و اینجا وارد کنید.

راهنمای استفاده

  1. کلید API را ذخیره کنید.
  2. به تب یوتیوب یا هر سایتی که صدا دارد بروید.
  3. روی آیکون افزونه کلیک کنید و «شروع دوبله» را بزنید.
  4. صدا به صورت زنده به فارسی ترجمه و پخش می‌شود.

نکات مهم

  • این افزونه روی Lemur Browser و کروم دسکتاپ کار می‌کند.
  • برای بهترین نتیجه از هدفون استفاده کنید.
  • هزینه استفاده از مدل بر اساس کلید خودتان محاسبه می‌شود (سطح رایگان معمولاً کافی است).
