If dubbing fails on Lemur

  1. Turn off livdub, Persian Live Dub, and any other tab-audio extension.
  2. Refresh the YouTube tab, start playback, then press Start.
  3. Use Test live connection here. If that fails, the key or network is the issue.
  4. If Lemur shows a site-access toggle for generativelanguage.googleapis.com, turn it on.
